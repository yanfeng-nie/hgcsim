# HGCSim 建模说明

本文档说明模拟器内部的性能、功耗与成本模型，以及它们的适用范围。模型定位是**趋势正确、量级合理**，用于比较调度与数据管理策略，而非预测某台真实机器的绝对性能。

## 1. 总体架构

```
           Python 前端 (Streamlit)  ──JSON──>  C ABI (libhgcsim.so)  ──>  C++ 内核
                                                                         ├─ params     参数系统（默认值/上下界/关系约束）
                                                                         ├─ memory     存储层级
                                                                         ├─ interconnect 互连链路
                                                                         ├─ devices    计算设备
                                                                         ├─ system     拓扑、校验、路由
                                                                         ├─ workload   负载解析模型 + 任务图生成
                                                                         └─ runtime    离散事件仿真（事件引擎、流级网络、内存管理、设备执行）
```

全部仿真逻辑在 C++ 中实现；Python 只负责组装 JSON 请求与可视化。

## 2. 参数系统

每个组件持有一个 `ParamSet`。每个参数有默认值、下界、上界、单位、说明，部分参数只允许离散取值（如 PCIe 通道数）。越界的配置被拒绝。**峰值性能永远由结构参数推导**，不能直接填写。组件的 `validate()` 再检查参数间的关系约束，例如：

- HBM3/3E（1024 bit）每引脚速率 ≤ 9.8 Gb/s、单栈容量 ≤ 48 GB；更高需 HBM4（2048 bit）
- GDDR 容量 ≤ 颗粒数 × 3GB × 2（双面贴装）
- DRAM 容量 ≤ 通道数 × 2 DIMM × 256GB
- Flash 容量 ≤ die 数 × 256GB；tProg ≥ tR
- CXL：x2 链路与捆绑端口仅 4.0；交换需 ≥ 2.0；交换机级联需 ≥ 3.0；设备/主机/交换机的版本能力都要满足
- PCIe 代数/通道数不超过设备与上游端口能力
- DDR 总线设备 + 主机 DRAM 通道总数 ≤ 24
- 每类器件的推导功耗不超过该类器件的功耗上界（散热/供电约束）
- 预算启用时：系统总功耗、总成本不超过预算

## 3. 存储层级

| 层级 | 峰值带宽推导 | 延迟 | 访问粒度 |
|---|---|---|---|
| HBM | 堆栈数 × 接口位宽 × 引脚速率 / 8 | 参数（默认 300ns，含设备侧） | 32/64B |
| GDDR | 总线位宽 × 引脚速率 / 8 | 参数（默认 350ns） | 32/64B |
| DRAM | 通道数 × 通道位宽/8 × MT/s | 参数（默认 90ns） | 64B |
| SCM | 模块数 × 单模块带宽（读写不对称） | 读/写延迟参数 | 64–4096B |
| Flash | min(NAND 通道数×通道速率, die数×页大小/tR, 主控上限) | tR + 10µs | 4KB |

- 顺序带宽 = 峰值 × 可达效率
- **随机访问**（每次 e 字节）：
  - 带宽上限 = 峰值 × 随机效率 / 放大系数，放大系数 = ⌈e/粒度⌉·粒度 / e
  - 并发上限（Little 定律）= 并发请求数 × e / (延迟 + 额外粒度传输时间)
  - Flash 额外受 IOPS 限制：min(主控 IOPS, die 数/tR)
  - 取三者最小值

## 4. 互连

- **PCIe**：有效带宽 = 速率(GT/s) × 通道数 / 8 × 编码效率 × MPS/(MPS+头) × 0.95(DLLP) × DMA 效率
  - 编码：Gen1–2 8b/10b；Gen3–5 128b/130b；Gen6–7 FLIT（236/256）
  - 头开销：Gen≤5 为 24B；Gen6+ 为 16B
  - 默认 Gen4 x16 ≈ 25.2 GB/s（与实测 cudaMemcpy 一致的量级）
- **CXL**：PHY 速率 1.1/2.0 = 32 GT/s，3.x = 64 GT/s，4.0 = 128 GT/s；flit 效率 68B 模式 0.79、256B 模式 0.86；带宽 × 捆绑端口数。每个端口穿越附加延迟（默认 25ns ×2），交换机延迟（默认 120ns），内存扩展器控制器延迟（默认 70ns）。
- **DDR 总线**：通道数 × 8B × MT/s × 效率（用于 PIM DIMM、持久内存 DIMM）
- **NVLink**：链路数 × 单链路单向带宽
- **介质链路**：每个存储层级通过一条“介质链路”连到所属设备，其带宽 = 存储顺序带宽，因此存储带宽本身也是网络中的一个瓶颈资源。

**路由**：在拓扑上搜索“最宽路径”（瓶颈带宽最大，其次延迟最小）。交换机下设备互访（P2P）需满足：PCIe 交换机开启 P2P；CXL 交换机两端链路与交换机均 ≥ 3.0。不满足时经主机根复合体“发夹”转发（同一上行链路正反各走一次）。

**零拷贝**：只有主机可见的字节寻址内存（主机 DRAM、CXL/DDR 内存扩展器）可被零拷贝访问，且路径须全程支持访存语义；PCIe 路径带宽乘以零拷贝效率（默认 0.6），CXL 乘以 load/store 效率（默认 0.85）；随机零拷贝再受“并发请求数 × 行大小 / 路径延迟”限制。

## 5. 流级网络模型

每条链路（全双工时每个方向）是一个带宽资源。并发传输（flow）沿路由占用多个资源，带宽按**渐进填充的最大最小公平**分配，并受每个 flow 自身上限约束（如 Flash 随机 IOPS、SCM/Flash 写带宽、NMP 主机传输效率）。任一 flow 开始或结束时重新分配。每次传输还有建立开销（DMA setup）与路径延迟。

## 6. 计算设备（扩展 Roofline）

```
t = 启动开销 + max(t_c, t_m) + 重叠惩罚 × min(t_c, t_m) + 设备特有开销
t_c = FLOPs / (峰值(精度, 算子) × 算子效率 × 形状效率)
t_m = 顺序字节 / 本地存储顺序带宽 + 随机访问时间
随机访问时间 = 未命中次数 × e / 随机有效带宽 + 命中次数 × e / 片上带宽
命中率 = min(0.95, (片上容量 / 工作集)^(1 - 偏斜度))
```

| 设备 | 峰值推导 | 主要特性 |
|---|---|---|
| CPU | 核数 × 频率 × FMA 单元 × SIMD 宽/32 × 2；AMX：每核每周期 1024 BF16 / 2048 INT8 | 并发未命中 = 核数 × LFB |
| GPU | SM × 频率 × 每 SM 每周期运算数（FP32 核 / Tensor Core × 精度倍数） | GEMM 形状按 64×32 分块计效率 |
| NPU | AI Core × 频率 × Cube MAC × 2；非 GEMM 走向量单元 | gather 效率参数（块式 DMA） |
| TPU | MXU 数 × 边长² × 2 × 频率 | 形状效率按阵列边长分块；无 SparseCore 时随机访问极弱 |
| FPGA | DSP × 利用率 × 频率 × 2 / 每 MAC 的 DSP 数 | 随机访问加成 1.5；访存与计算完全重叠；LRU 驻留内核，未驻留需重配置 |
| NMP | 单元数 × 频率 × 每周期运算（整数/浮点分别给出） | 内部带宽 = 单元数 × 单元带宽；8B 粒度随机访问；halo 经主机或片上网络 |
| CSD | 盘内算力参数 | 本地存储即盘内闪存（内部带宽），DRAM 缓冲为缓存 |
| CIM（RRAM/MRAM） | 阵列数 × 行 × 列 / 位切片数 × 2 / t_MVM | 见下 |

**存算一体**：
- 位切片数 = ⌈权重位宽 / 单元位数⌉；t_MVM = ⌈输入位宽/DAC 位数⌉ × ⌈行数/激活行数⌉ × ⌈列数/每阵列 ADC 数⌉ / ADC 采样率
- 权重矩阵 K×N 需要 ⌈K/行⌉ × ⌈N/列⌉ × 切片数 个阵列块；放得下时可复制 ⌊阵列数/块数⌋ 份并行处理输入向量；放不下时每次调用都分轮重编程
- 编程时间 = ⌈块数/并行写入阵列数⌉ × 行数 × 单行写入时间；同一 `weight_id` 的静态权重只编程一次
- 无损所需 ADC 位数 ≈ log2(激活行数) + 单元位数 + DAC 位数 − 1，不足时给出精度告警；跟踪单元写入次数 / 耐久
- 只支持 int8/int4 GEMM（及数字外围上的逐元素、归约、Top-k），不支持 SpMM / 排序 / 散射

## 7. 负载模型

记 N 节点、E 边、d 特征维、编码器维度序列 d→h1→…→h、k 簇、P 分块、e_b 嵌入字节数：

| 算子 | FLOPs | 顺序字节 | 随机访问 |
|---|---|---|---|
| 编码器（推理） | N_c·Σ 2·d_i·d_{i+1} | N_c·d·4 + N_c·h·e_b + 中间激活 | — |
| 编码器（训练，每 epoch） | × train_flops_factor（默认 6） | × 2 | — |
| CSR 构建 | 10·E_c | 4 遍基数排序 × 2 × E_c × 8 + CSR 输出 | 2·E_c 次 4B（度统计/归一化，工作集 N×4） |
| kNN 建图 | 2·N_c·N·h（候选比例可调） + Top-k | 全部嵌入流式读入 | — |
| SpMM 传播 | 2·E_c·h | CSR + 2·N_c·h·e_b | E_c 次 h·e_b 字节（工作集含 halo 行） |
| 分配 GEMM | 2·N_c·h·k + … | N_c·h·e_b | — |
| METIS 划分（主机） | 20·E | 80·E 字节 | 5·E 次 8B |

- **割边比例**：random = 1−1/P；range = (1−1/P)(1−locality)；metis = min(1−1/P, base·log2 P)
- **halo 行数**（球-盒模型）：other·(1 − exp(−cut·E_c/other))，other = N − N_c
- 跨分块依赖在每一跳形成全局同步（BSP）；K-means 每轮在 leader 上归约中心

## 8. 运行时

- 任务按数据依赖自动生成 DAG；`overlap=false` 时各阶段之间额外加全局栅栏
- 每个设备同时执行一个 kernel；`overlap=true` 时最多 `prefetch_depth+1` 个任务处于“准备/就绪/执行”窗口
- 准备任务时为缺失输入分配本地空间（LRU 逐出未被固定的副本；唯一副本先写回其 home 层），再发起传输；所有输入到达后才可执行
- 数据块有多个副本时从路径带宽最大的副本读取
- 动态分配：分块就绪时计算各候选设备的“最早完成时间”（排队 + 输入搬运 + 计算），或交给插件 `select_device`
- 所有消费者完成后数据块被释放

## 9. 功耗、能耗与成本（简化估算）

- 能耗 = Σ kernel（FLOPs × pJ/FLOP × 位宽/32 + 访存字节 × 存储 pJ/bit）+ Σ 传输（字节 × 路径各段 pJ/bit）+ 静态功耗 × 完成时间
- 器件峰值功耗与成本由结构参数估算（公式见 `src/devices.cpp` 各设备的 `tdp_w()` / `cost_usd()`、`src/memory.cpp` 的 `cost_usd()`），量级参考同类产品，**仅用于协同设计赛道的预算约束**，不代表真实报价。

## 10. 局限性

- 不建模缓存一致性协议细节、NUMA、操作系统与驱动排队、温度降频
- 算子效率是经验常数而非微架构仿真；聚类的收敛性与精度不建模（精度选择对准确率的影响需在报告中讨论）
- 网络为流级模型，不模拟包级拥塞与信用流控
- 数据集用统计量（度偏斜、局部性、割边基数）概括，不读取真实图
